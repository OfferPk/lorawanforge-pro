\# LoRaWANForge Pro (v1.0.0) — Operator & Engineer User Guide

\#\# 1\. Quick Start Guide

\#\#\# 1.1 Web Application Studio  
Launch \`source-code/index.html\` directly in any modern web browser. No Node.js, Python, or external server is required.  
\- \*\*Tab 1: Frame Dissector\*\*: Paste raw PHYPayload hex or base64 to inspect decoded MHDR, DevAddr, FCnt, FOpts, and MIC validation with 1-click PCAP export.  
\- \*\*Tab 2: Uplink / Downlink Synthesizer\*\*: Specify DevAddr, FCnt, FPort, cleartext payload, and keys to generate valid encrypted LoRaWAN frames and Semtech UDP forwarder JSON.  
\- \*\*Tab 3: PHY Airtime & Duty-Cycle\*\*: Calculate exact packet airtime (ms), symbol durations, and maximum allowable transmission rates under regional regulatory caps.  
\- \*\*Tab 4: LoRa Alliance Security Auditor\*\*: Audit device and network server configurations across 10 security controls.  
\- \*\*Tab 5: Gateway Firewall & IDS Rules\*\*: Generate ready-to-deploy Linux \`nftables\` gateway rules and Suricata Layer 7 intrusion detection signatures.

\#\#\# 1.2 Standalone Python CLI (\`lorawanforge-cli.py\`)  
Run directly from the command line using Python 3.8+. The script is completely self-contained.

\`\`\`bash  
\# Make CLI executable  
chmod \+x build/lorawanforge-cli.py

\# 1\. Calculate Airtime for a 20-byte payload at SF7 / 125 kHz  
./build/lorawanforge-cli.py airtime \--payload-bytes 20 \--sf 7 \--bw 125

\# 2\. Calculate Airtime for SF12 / 125 kHz (Long Range Profile)  
./build/lorawanforge-cli.py airtime \--payload-bytes 20 \--sf 12 \--bw 125

\# 3\. Synthesize LoRaWAN Unconfirmed Uplink Frame  
./build/lorawanforge-cli.py build-uplink \--devaddr 01020304 \--fcnt 1 \--payload 01670110

\# 4\. Synthesize Confirmed Uplink Frame  
./build/lorawanforge-cli.py build-uplink \--devaddr 01020304 \--fcnt 5 \--payload DEADBEEF \--confirmed

\# 5\. Dissect raw LoRaWAN PHYPayload hex  
./build/lorawanforge-cli.py dissect "4004030201000100011234567890abcd"

\# 6\. Run LoRa Alliance zero-trust cybersecurity audit  
./build/lorawanforge-cli.py audit

\# 7\. Synthesize nftables gateway rules and Suricata signatures  
./build/lorawanforge-cli.py synthesize-firewall \--lns-ip 10.0.50.10

\# 8\. Export sample LoRaWAN packet forwarder traffic to Wireshark PCAP  
./build/lorawanforge-cli.py export-pcap \--out lorawan\_sample.pcap

\#\# 2\. CLI Command Reference

\#\#\# \`airtime\`  
Calculates exact physical layer transmission airtime in milliseconds.  
\- \`--payload-bytes\`: Total PHYPayload size in bytes (MHDR \+ MACPayload \+ MIC). Default: \`23\`.  
\- \`--sf\`: Spreading Factor (\`7\`, \`8\`, \`9\`, \`10\`, \`11\`, \`12\`). Default: \`7\`.  
\- \`--bw\`: Channel bandwidth in kHz (\`125\`, \`250\`, \`500\`). Default: \`125\`.  
\- \`--cr\`: Coding Rate denominator offset (\`1\`=4/5, \`2\`=4/6, \`3\`=4/7, \`4\`=4/8). Default: \`1\`.

\#\#\# \`build-uplink\`  
Constructs a valid encrypted LoRaWAN data uplink frame.  
\- \`--devaddr\`: 4-byte device address hex string (e.g. \`01020304\`).  
\- \`--fcnt\`: Uplink frame counter integer. Default: \`1\`.  
\- \`--fport\`: Application port (\`1\` to \`223\`). Default: \`1\`.  
\- \`--payload\`: Cleartext application payload hex string (e.g. \`01670110\` for Cayenne LPP temperature).  
\- \`--nwkskey\`: 16-byte Network Session Key hex string for MIC calculation.  
\- \`--appskey\`: 16-byte Application Session Key hex string for payload CTR encryption.  
\- \`--confirmed\`: Flag to set Confirmed Data Up (MType 4).

\#\#\# \`dissect\`  
Decodes raw hex or base64 LoRaWAN frames, displaying MType, DevAddr, FCnt, FOpts MAC commands, and payload length.

\#\#\# \`export-pcap\`  
Generates a Libpcap 2.4 capture file containing synthetic Ethernet, IPv4, UDP (Port 1700), and Semtech UDP forwarder frames for Wireshark analysis.

\#\# 3\. Engineering Reference & FAQs

\*\*Q: How do I open LoRaWAN packets in Wireshark?\*\*  
A: In Wireshark, navigate to \`Analyze \-\> Enabled Protocols\`, ensure \`LoRaWAN\` and \`Semtech UDP Packet Forwarder\` are enabled, and load the \`.pcap\` generated by LoRaWANForge Pro.

\*\*Q: What is the maximum payload size for LoRaWAN?\*\*  
A: Depending on regional parameters and data rate (DR), maximum payload sizes range from 51 bytes (DR0 / SF12 at 125 kHz in EU868) to 222 bytes (DR5 / SF7 at 125 kHz).
